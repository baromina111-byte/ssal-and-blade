# 쌀과 칼 — 조선 미곡 상단기

임진왜란 말기(1595~1597), 남원의 평민 **덕수**가 쌀장사로 팔도의 거상이 되기까지의
2년을 다룬 **2D 액션 + 경영 시뮬레이션**입니다. 브라우저에서 바로 돌아갑니다.

**▶ 지금 하기 — https://baromina111-byte.github.io/ssal-and-blade/**

- 무기 26자루 · 전장 19곳 · 이벤트 225종 · 결말 6가지
- 배경은 실제 연표 — 화의 결렬, 칠천량, 남원성, 명량
- 조작: `←→` 이동 · `W` 점프 · `A` 공격 · `S` 방어 · `D` 대시 · `1` `2` 무예
- 모바일은 화면을 가로로 돌리면 터치 패드가 뜹니다

빌드 도구도 프레임워크도 외부 라이브러리도 없이 순수 ES 모듈과 Canvas 2D로 만들었습니다.
